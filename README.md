# Plant Classification Machine Learning Project

## Overview
This project utilizes machine learning techniques for the classification of various plant species based on images. Jupyter Notebooks are used for data exploration, model training, and evaluation.

## Features
- Image classification using Convolutional Neural Networks (CNNs)
- Data augmentation techniques to improve model performance
- Visualization of class distributions and model evaluations

## Requirements
- Python 3.x
- Libraries: TensorFlow, Keras, NumPy, Pandas, Matplotlib, scikit-learn

## Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/sumitk208/PlantClassification.git
   ```
2. Navigate to the project directory:
   ```bash
   cd PlantClassification
   ```
3. Install the required libraries:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
- Open the Jupyter Notebook files in the `notebooks` directory to explore the data and run the models.
- Follow the instructions in each notebook for detailed steps.
